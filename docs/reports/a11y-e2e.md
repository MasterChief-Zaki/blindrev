## Exceptions granted

- **Inline links in text:** the rule is implemented, but no inline link was found on any audited screen (0 granted).
- **Spacing-equivalent (WCAG 2.5.8) exception:** **none granted.** The pair buttons (36×32) are adjacent to each other and to the step columns, so no clear 24 px spacing argument holds, and SPEC §15 asks for 44.
- **Focus-ring offset:** `map-focus` (full-viewport mission map, `role=application`) uses an **inset −8 px** outline. It is accepted as a visible focus indicator because a positive offset would be off-screen. It is a deviation from the +5 px token, not a hidden ring.
- Roving-tabindex items (`role=tab`, MenuList rows with `tabindex=-1`) are excluded from the Tab-reachability check (they are reached with the arrow keys). They are still size-checked.

## App defects found (for the orchestrator; app code not touched)

1. **Mission HUD: timeline A/B pair buttons below 44×44.** Elements: `timeline-pair-a-<0..8>` and `timeline-pair-b-<0..8>`. Expected ≥ 44×44 (SPEC §15; the ui-hud README also says every target is ≥ 44×44). Actual: 36×32. Failing assertion: `targets-focus.spec.ts` › "targets ≥ 44×44 and visible focus on Tab — mission" › `targets < 44×44 on mission`. Owner: ui-hud `TemporalTimeline` (U), or F's timeline-density pass.
2. **Mission HUD: panel hide toggles below 44 px tall.** Elements: `toggle-left-close` "◂ Hide" is 67.8×32 and `toggle-right-close` "Hide ▸" is 53.3×43; expected ≥ 44×44. Same failing assertion. Owner: F (new in the layout pass).
3. **Focus-ring offset ≠ 5 px token** (ring is visible; not gated). Affected: `menu-new` (2 px), the hub case cards (3 px), the journal row header (2 px), the settings segmented options (3 px), and the mission panel toggles (3 px). Expected `outline-offset: 5px` (SPEC §8/§15). Owner: U/F CSS.
4. **Hub clock ignores the `?now=` fixed clock.** `packages/app-shell/src/screens/Hub.tsx:25-27` uses `new Date()` instead of `nowDate()`, so the hub HUD shows wall-clock time (e.g. "20:35:44 / 2026-11-15 UTC" while `now=…T18:00:00Z`). This makes the visual fixture non-deterministic; it currently stays under the 2 % diff threshold. No failing assertion. Owner: F.
