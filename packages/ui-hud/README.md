# @blindrev/ui-hud — Outpost Signal design system

React 19 components, vanilla CSS (class prefix `br-`), no CSS framework. Presentational and props-only: no Cesium or Three.

```ts
import "@blindrev/ui-hud/styles.css"; // tokens + self-hosted fonts + base + every component's CSS
import { Button, TemporalTimeline, RoiEditor2D, initSound } from "@blindrev/ui-hud";
```

- Tokens: `src/styles/EARTH_exe_Outpost_Tokens.css` (`--color-*`, `--fs-*`, `--space-*`, `--radius-*`, `--motion-*`, `--ease`, `--ramp-*`, `--z-*`, `--scrim*`).
- Reduced motion: `prefers-reduced-motion` **or** the class `br-reduced-motion` on `<html>` removes all transitions and animations. Components that change behaviour (not just styling) also take a `reducedMotion` prop.
- Focus ring: 2 px cyan with a 5 px offset on everything focusable. Every interactive target is at least 44×44 px.
- Gallery: run `pnpm --filter @blindrev/ui-hud dev` and open http://localhost:5183/. Add `?modal=1` to open the modal on load, or `?rm=1` to start with reduced motion on. The gallery serves `app-shell/public` as its public folder, so the real sounds play.

## TemporalTimeline

- One column per step, evenly spaced by **index** (steps are discrete; spacing them by date would imply interpolation). Each column shows the date in Plex Mono and the instrument. Platform, instrument, processing version and track are in the `title` tooltip and in the "now" caption.
- Unavailable steps are hatched with an amber dashed tick and the words "No acquisition". They are never hidden or interpolated, and A/B cannot be set on them (`aria-disabled`).
- The current step has a cyan frame and caret. The state chip shows `WATCH Ready / Playing / Paused — no acquisition / Scrubbing`.
- The track is `role="slider"` (`data-testid="timeline-track"`) with `aria-valuetext` like `"Step 4 of 9, 2026-03-14, NISAR L-SAR, available"` (plus ", marked A, baseline" when marked).
  Keys: ←/↓ call `onStep(-1)` and →/↑ call `onStep(1)`. Home/End call `onScrubStart(); onScrubTo(0|n-1); onScrubEnd()`. Space plays or pauses (disabled under reduced motion). **A** and **B** mark the current step.
- Pointer: press or drag on the track calls `onScrubStart` → `onScrubTo(i)` (each time the index changes) → `onScrubEnd` on release, with pointer capture.
- Pair: per-step buttons `timeline-pair-a-<i>` and `timeline-pair-b-<i>`. Clicking a set flag clears it, and setting A on B's step moves it. The summary bar shows A (baseline), B (compare) and **Δt in whole days** (`timeline-dt`). The amber inline warning `timeline-pair-warning` appears when Δt < `dtMinDays`, when A is after B (with a "Swap A and B" button), or when a marked step is unavailable. There is also a "Clear pair" button.
- `reducedMotion`: the play button becomes an explanatory, focusable, `aria-disabled` control reading "Auto-play is off — reduced motion" (still `data-testid="timeline-play"`, `data-reduced-motion="true"`). Stepping and scrubbing still work.
- You own the timer: dispatch `TICK` while `state === "PLAYING"` and not reduced motion. The timeline itself does not announce anything; announce the FSM emissions with `announce()`. The gallery's `TimelineDemo` in `gallery/main.tsx` is a working reference wired to `createTemporalWatch`.
- Other testids: `timeline`, `timeline-step-<i>` (has `data-available`), `timeline-back`, `timeline-forward`, `timeline-play`, `timeline-state`, `timeline-pair-summary`, `timeline-pair-swap`, `timeline-pair-clear`.

## RoiEditor2D

- SVG map of `bounds`. Mapping is linear in lon/lat, and the canvas aspect is corrected by cos(mid-latitude) (`editorSizeForBounds`). `backdropUrl` and `overlayUrls[]` are stretched exactly over `bounds` (single-tile rasters). The graticule has Plex Mono lon/lat labels on scrims, thinned so they never collide. The `CURSOR` (keyboard) and `POINTER` readouts sit under the map (`roi-readout`).
- Pointer: click empty map to add a vertex. Click vertex 01 (amber ring once there are ≥ 3 points) or "Close shape" to close. Drag a vertex to move it. Click a vertex to select or deselect it. **Single-pointer alternative to dragging:** select a vertex, press "Move here" (`roi-move`), then click the destination.
- Keyboard: the canvas (`roi-canvas`, `role="application"`) is in the tab order. Arrows move the keyboard cursor by 1/50 of the span (Shift ×5) when nothing is selected. Enter/Space adds a vertex at the cursor (or moves the selected vertex there in Move mode). `C` closes the shape. `[` and `]` cycle the selection. With a selection, arrows nudge it with core-sim `nudgeVertex` by `nudgeDeg` (Shift × `coarseFactor`). Delete/Backspace removes it, Esc deselects (and calls `preventDefault`, so a surrounding Modal stays open), and Ctrl/Cmd+Z undoes.
- Vertex table: index, plus lon/lat number inputs shown to 4 dp (`roi-lon-<i>`, `roi-lat-<i>`). Inputs commit on every valid keystroke, so Playwright `fill()` works, and each focus session is one undo step. There are also select (`roi-select-<i>`) and delete (`roi-delete-<i>`) buttons, and "Add point at cursor" (`roi-add`).
- Clear: the danger button (`roi-clear`) opens an inline confirm, `roi-clear-confirm` / `roi-clear-cancel`. Undo: `roi-undo`. The editor keeps its own undo history; it resets on unmount.
- Validation: pass `validateRoi(...)` from core-sim, or `null`. The status box (`roi-status`) shows Valid / Needs fixing / Add N more points / Open shape. Area appears as `NNN.N km²` (`roi-area`), or `NOT MEASURED` when there is no validation. Errors are listed with an icon and words (`roi-errors`). A valid closed shape is drawn cyan and solid; an invalid one magenta and dashed; an open one pearl and dashed.
- `onChange` is called with `closed=false` whenever there are fewer than 3 vertices. Vertices placed by pointer are rounded to 1e-6°.
- It announces changes politely (point added, moved, deleted, selected, cursor position, shape closed or cleared).
- Root `data-testid="roi-editor"` has `data-status="valid|invalid|open|empty"` and `data-closed`. Vertices are `roi-vertex-<i>`. The points table is `roi-points-table`, deliberately **not** `roi-vertex-…`, so `[data-testid^="roi-vertex-"]` counts vertices only.
- Pure helpers (unit-tested): `lonLatToEditor(p, bounds, size)`, `editorToLonLat(pt, bounds, size)`, `editorSizeForBounds(bounds, width=1000)`, `clampToBounds`, `roundDeg`, `niceStep`, `graticuleLines`, `formatLat`, `formatLon`.

## Sound

```ts
initSound({ baseUrl: new URL("audio/", document.baseURI).href }); // once, at startup
playSound("press" | "confirm" | "alert" | "scan" | "travel");
setAmbient(true);
setSoundEnabled(false);
setVolume(0.6);
getSoundStatus();
```

WebAudio. Nothing is created before the first user gesture (pointerdown/keydown/touchstart), and every call is a silent no-op when sound is disabled, unsupported or not yet unlocked. Roles with no file, or whose file fails to load, fall back to a soft synthesised beep. `Button`, `Toggle`, `Tabs`, `ReturnButton`, `ToolButton`, `MenuList` and the timeline pair buttons play `press` automatically. Suggested calls for you: `travel` when the wipe starts, `scan` on `StepChanged`, `confirm` on "Evidence saved" or a passing verdict, `alert` on `NoAcquisition` / rejected / QA diagnostic.
